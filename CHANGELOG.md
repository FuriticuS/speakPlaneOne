# Changelog

Все значимые изменения проекта будут описаны в этом файле.

## [v0.0.1] - 2026-08-04

### Added
- Базовая структура Express API
- Аутентификация backend: регистрация, вход, выход, получение текущего пользователя
- JWT: access token и refresh token
- Работа с PostgreSQL через пул подключений
- Валидация входных данных с помощью Zod
- Схемы для основных сущностей: project, page, block
- Базовые модули по структуре: routes, controllers, services
- Подключение новых маршрутов к серверу
- Таблицы в базе данных для пользователей, refresh token, проектов, страниц и блоков
- Базовые тесты для проверки ключевой логики и валидации
- Создали базу postgresql пароль как обычно порт 5432

### Changed
- Организована модульная структура backend-проектa для дальнейшего расширения
- Вынесена логика валидации и схемы в отдельные модули

### Notes
- Это первая рабочая версия чернового backend-этапа
- Проект готов для дальнейшего развития и добавления полноценной бизнес-логики
